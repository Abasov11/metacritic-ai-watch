Записано до начала разработки. Отчёт по каждому пункту — ниже, в скобках чем проверено.
Дата отчёта: 2026-09-06 (обновлён после ревью, шаг 7).

## Обязательная часть
- [x] D1. Планировщик: раз в час запускается обход; за обход берётся 20 игр, которые

- [x] D2. Первый обход дня — New Releases; следующие — страницы «SEE ALL / New» по

      повторялись. Сброс дня и ротация — `test_later_runs_the_same_day_walk_browse_pages`,
      `test_a_new_day_starts_over_at_new_releases`, `test_day_boundary_uses_the_configured_timezone`.
- [x] D3. Сохраняются название, обложка, платформы с Metascore и Userscore,
      разработчик, описание, ссылка на видео.

      скачаны локально. Пример из прода — Onimusha: Way of the Sword, 4 платформы, у

      Userscore по платформам берётся отдельным запросом: на карточке игры его нет.
- [x] D4. Повторный обход обновляет запись, а не дублирует.
      — `test_recrawl_updates_instead_of_duplicating`; живьём повторный обход не создал

- [x] D5. LLM-резюме отдельно по критикам и игрокам, обновляется при повторных обходах.
      — В прод-базе 583 резюме, из них 37 написаны моделью по настоящим отзывам
      (24 игры); у остальных отзывов на Metacritic ещё нет, и там честная заметка
      «Отзывов пока нет» без вызова модели
      (`test_missing_reviews_get_a_note_not_a_summary`). Всего 455 вызовов модели на
      $0.1308, ошибок 0. Качество резюме отдельно проверено судьёй — см.
      `docs/EVAL_SUMMARIES.md`.
- [x] D6. Веб: список, карточка, фильтр по платформам, поиск, сортировка по рейтингу.
      — 23 теста в `tests/test_web.py`; живьём `/`, `/game/<slug>`,
      `/api/games?platform=PC&sort=metascore_desc&q=onimusha` отдают 200.
- [x] D7. Похожие игры из базы в карточке, клик открывает карточку.
      — Гибрид: 0.6 × jaccard по тегам из закрытого словаря + 0.4 × TF-IDF, порог
      отсекает случайных соседей (`test_similar_games_ranks_the_closest_first`).
      Теги проставлены всем 292 играм. Живьём в карточке Onimusha — The Blood of
      Dawnwalker (0.306, общее: action, combat, exploration) и другие, у каждой

- [x] D8. Сервис доступен по публичной https-ссылке и работает автономно, переживает
      рестарт.
      — Развёрнут владельцем сервера под systemd на порту 8012 за nginx:
      **https://skytec.213-32-66-46.nip.io**. Проверено им же: открывается список игр,
      карточка игры, страница мониторинга, SSE-поток идёт через nginx. Образ отдельно
      проверен сборкой и запуском через rootless podman (245 МБ, `/healthz` отвечает,
      база создаётся в томе) — демона Docker на сервере нет. Переживание рестарта на
      уровне кода: схема создаётся при старте, оборванные обходы помечаются `aborted`
      (`test_a_run_left_running_by_a_dead_process_is_closed_at_startup`).
- [x] D9. Репозиторий с README: запуск локально, переменные окружения, архитектура.
      — `README.md`: схема, логика выбора игр, таблица из 19 переменных, docker и
      systemd, ограничения. `make dev` / три команды. `make lint` проверен.
- [x] D10. Переписка с нейросетью приложена raw JSONL и проверена на отсутствие
      секретов.
      — В `transcripts/` (30 файлов, 9.5 МБ): полный лог основной сессии
      `session-7e214985-main.jsonl`, лог отдельной сессии-проверки, промпты всех шагов
      в `prompts/`, логи субагентов в `subagents/`, крупные выводы в `tool-results/`,
      и `transcripts/README.md` с картой файлов.
      **Проверка на секреты:** grep по `sk-or-v1-…`, `OPENROUTER_API_KEY=<значение>`,
      `__Secure-3PSID=<значение>` — реальных ключей и кук нет. Два совпадения на
      `sk-or-` — ложные: это моя же маскирующая регулярка
      `sed -E 's/(sk-or-[A-Za-z0-9_-]+)/<redacted>/g'` в тексте команд. Значения
      `OPENROUTER_API_KEY=` в логах всегда пустые или `<redacted>`. `.env` и
      `data/youtube-cookies.txt` в git не отслеживаются (`git ls-files` их не
      показывает).

## Ревью перед сдачей (шаг 7)
- [x] R1. Security-review по всему дереву.
      — 5 кандидатов, все отфильтрованы как ложные срабатывания (уверенность 8-9):
      CSRF на `/monitor/run` (нет ambient authority — авторизации нет нигде),
      отсутствие заголовков (hardening), схема URL в ссылках (нет управляемого
      источника), утечка ошибок (ключ Metacritic публичный, OpenRouter в заголовке),
      prompt injection (модель без инструментов). Подробности — в отчёте шага 7.
- [x] R2. Меры защиты внедрены сверх находок.
      — CSP без `unsafe-inline`, `X-Frame-Options`, `nosniff`, `Referrer-Policy`;
      same-origin + лимит частоты на `POST /monitor/run`; белый список схем в ссылках;
      вычистка секретов из текста ошибок; ограничения на размер входа; проверка слага.
      30 тестов в `tests/test_security.py`.
- [x] R3. Code-review (high) по `app/`.
      — 6 находок, все приняты и исправлены: протокол-относительные `//host` в
      `safe_url`, CSP резал обложки-фолбэки и инлайн-стиль htmx, `0.0` как sentinel
      против `time.monotonic()`, порт в `Origin` против `Host`, `is_error` вместо
      `not is_success`. Каждая покрыта тестом.
- [x] R4. `pip-audit` чист.
      — Была одна находка (сам `pip` 24.0, 7 CVE); обновлён до 26.2.1, в `Dockerfile`
      добавлен `pip install --upgrade pip`. Зависимости приложения чисты.
- [x] R5. Оборванные обходы.
      — Процесс, убитый посреди обхода, больше не оставляет строку `running`: при
      старте она помечается `aborted` с причиной и отдельным цветом на `/monitor`.

## После приёмки (шаг 8)
- [x] P1. Воркер `youtube` в мониторинге больше не заглушка: при `YOUTUBE_ENABLED=1`
      стартует в `idle`, `off` только когда стадия выключена настройкой (тесты на оба
      случая).
- [~] P2. Ложные совпадения летсплеев для коротких названий.
      — Для названий в 1-2 значимых слова нужна точная фраза и в заголовке, и в
      описании; для названий из 3 слов — все слова целиком; для длинных остался порог
      60%. Для любых обязателен маркер прохождения; ссылка на магазин — тайбрейк, а не
      пропуск. Живая проверка: `i-am-angel`, `flip-off`, `tilefall` →
      «подходящий летсплей не найден» (было: клип Eurythmics на 51 млн, ролик про GTA V,
      туториал по Stumble Guys), `onimusha-way-of-the-sword` → прежний theRadBrad.
      Пересчитаны все 42 записи: 35 без изменений, 5 заменены на правильные ролики,
      2 отброшены. **Остаточный случай:** названия целиком из общеупотребительных слов
      (`kupala` против праздника «Kupala Night», `kitty-needs-a-home`) — фраза совпадает
      честно, различить без базы названий игр нечем.
