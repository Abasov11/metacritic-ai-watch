## Ревью перед сдачей (шаг 7)
- [x] R1. Security-review по всему дереву.
      — 5 кандидатов, все отфильтрованы как ложные срабатывания (уверенность 8-9):
      CSRF на `/monitor/run` (нет ambient authority — авторизации нет нигде),
      отсутствие заголовков (hardening), схема URL в ссылках (нет управляемого
      источника), утечка ошибок (ключ Metacritic публичный, OpenRouter в заголовке),
      prompt injection (модель без инструментов). Подробности — в отчёте шага 7.
- [x] R2. Меры защиты внедрены сверх находок.
      — CSP без `unsafe-inline`, `X-Frame-Options`, `nosniff`, `Referrer-Policy`;
      same-origin + лимит частоты на `POST /monitor/run`; белый список схем в ссылках;
      вычистка секретов из текста ошибок; ограничения на размер входа; проверка слага.
      30 тестов в `tests/test_security.py`.
- [x] R3. Code-review (high) по `app/`.
      — 6 находок, все приняты и исправлены: протокол-относительные `//host` в
      `safe_url`, CSP резал обложки-фолбэки и инлайн-стиль htmx, `0.0` как sentinel
      против `time.monotonic()`, порт в `Origin` против `Host`, `is_error` вместо
      `not is_success`. Каждая покрыта тестом.
- [x] R4. `pip-audit` чист.
      — Была одна находка (сам `pip` 24.0, 7 CVE); обновлён до 26.2.1, в `Dockerfile`
      добавлен `pip install --upgrade pip`. Зависимости приложения чисты.
- [x] R5. Оборванные обходы.
      — Процесс, убитый посреди обхода, больше не оставляет строку `running`: при
      старте она помечается `aborted` с причиной и отдельным цветом на `/monitor`.

- [x] P1. Воркер `youtube` в мониторинге больше не заглушка: при `YOUTUBE_ENABLED=1`
      стартует в `idle`, `off` только когда стадия выключена настройкой (тесты на оба

      — Для названий в 1-2 значимых слова теперь нужна точная фраза и в заголовке, и в
      описании; для любых названий обязателен маркер прохождения; ссылка на магазин —
      тайбрейк, а не пропуск. Живая проверка: `i-am-angel`, `flip-off`, `tilefall` →
      «подходящий летсплей не найден» (было: клип Eurythmics на 51 млн, ролик про GTA V,
      туториал по Stumble Guys), `onimusha-way-of-the-sword` → прежний theRadBrad.
      Записи в базе обновлены. **Остаточный случай:** `kupala` — игра «Kupala» против
      праздника «Kupala Night» в роликах про Cabernet и Black Book; фраза совпадает
      честно, различить без базы названий игр нечем.
