# Definition of Done — критерии приёмки

Записано до начала разработки. В конце отчёт по каждому пункту отдельно.

## Обязательная часть
- [ ] D1. Планировщик: раз в час запускается обход; за обход берётся 20 игр, которые сегодня ещё не обрабатывались.
- [ ] D2. Первый обход дня — New Releases с https://www.metacritic.com/game/ ; следующие — страницы «SEE ALL / New» по очереди; новый день — счётчик страниц сбрасывается.
- [ ] D3. Для игры сохраняются: название, обложка, платформы с Metascore и Userscore (много платформ), разработчик, описание, ссылка на видео.
- [ ] D4. Повторный обход обновляет запись, а не дублирует.
- [ ] D5. LLM-резюме отзывов: отдельно критики, отдельно пользователи («что нравится / что нет»), обновляется при повторных обходах.
- [ ] D6. Веб: список игр с краткой информацией; карточка с полной информацией; фильтр по платформам; поиск по названию; сортировка по рейтингу.
- [ ] D7. Похожие игры из базы в карточке; клик по имени открывает карточку.
- [ ] D8. Сервис доступен по публичной https-ссылке и работает автономно (systemd/docker), переживает рестарт.
- [ ] D9. Репозиторий с README: запуск локально одной командой, переменные окружения, архитектура.
- [ ] D10. Переписка с нейросетью приложена raw JSONL и проверена на отсутствие секретов.

## Дополнительная часть 1
- [ ] E1. Для игры найден самый популярный летсплей на YouTube, речь блогера переведена в текст, по тексту сделано заключение, в карточке — заключение + ссылка на ролик.

## Дополнительная часть 2
- [ ] E2. В веб-интерфейсе мониторинг в реальном времени: статусы воркеров, счётчики обработанного, лог последних событий.
- [ ] E3. Кнопка принудительного запуска обхода.

## Проверка
- [ ] V1. Живой прогон обхода на проде: игры появились в базе, резюме сгенерированы, карточки открываются.
- [ ] V2. Проверен сброс «нового дня» и ротация страниц (тестом на подменённой дате).
- [ ] V3. Ошибка LLM/сети не роняет воркер, игра помечается и повторяется в следующий обход.
