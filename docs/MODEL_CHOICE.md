# Выбор LLM-модели (OpenRouter)

Дата: 2026-09-06. Сравнение на одном промпте: 20 реальных пользовательских отзывов на
Hollow Knight: Silksong → резюме по-русски строгим JSON (`likes`, `dislikes`, `summary`).
Критерии: качество и конкретность пунктов, соблюдение JSON, время, цена за вызов.

| Модель | Время | Токены (in/out) | Цена вызова | JSON | Оценка |
|---|---|---|---|---|---|
| deepseek/deepseek-v4-flash | 5.4 s | 1759/640 | $0.00024 | ok | конкретно, упоминает точки сохранения, боссов, сравнение с первой частью |
| google/gemini-2.5-flash-lite | 1.3 s | 1727/218 | $0.00026 | ok | быстро, чуть общее |
| google/gemini-3.1-flash-lite | 1.7 s | 1727/192 | $0.00072 | ok | хорошо, в 3 раза дороже |
| z-ai/glm-5.3-flash | 11.5 s | 1719/873 | $0.00069 | ok | очень подробно, медленно |
| openai/gpt-4.1-mini | 2.8 s | 1714/199 | $0.00100 | ok | хорошо, в 4 раза дороже |
| openai/gpt-5-mini | 9.4 s | 1713/723 | $0.00187 | ok | хорошо, дорого и медленно |
| qwen/qwen3.7-flash | — | — | — | пустой ответ | отклонён |

**Решение:** основная модель `deepseek/deepseek-v4-flash`, резервная при ошибке/таймауте
`google/gemini-2.5-flash-lite`. При 20 играх в час × 2 резюме (+1 заключение по летсплею)
это ≈ 1500 вызовов в сутки ≈ $0.40/день на основной модели.

Эмбеддингов у OpenRouter нет, поэтому «похожие игры» считаются локально (TF-IDF по
описанию, жанрам, разработчику и платформам), без обращений к LLM.
