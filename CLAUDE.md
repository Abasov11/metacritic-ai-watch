# Правила проекта metacritic-ai-watch

Тестовое задание — текст в `docs/TASK.md`, критерии приёмки в `docs/DOD.md`. Читать оба перед работой.

## Стек (не менять без причины)
- Python 3.12, виртуальное окружение `.venv` (система externally-managed: `python3 -m venv .venv && .venv/bin/pip install -e .[dev]`).
- FastAPI + Uvicorn, SQLAlchemy 2 + SQLite (файл `data/app.db`), APScheduler, httpx, selectolax, Jinja2 + HTMX, pytest.
- Секреты только в `.env` (в `.gitignore`), пример — `.env.example`. Ключи в код и в коммиты не попадают.
- Без Playwright/Selenium: Metacritic отдаёт SSR-страницы обычным HTTP-клиентом с браузерным User-Agent.

## Как работать
- Маленькие осмысленные коммиты, сообщения по-английски в стиле `feat: …`, `fix: …`, `test: …`, `docs: …`.
- Сначала тест на сохранённой фикстуре, потом живой прогон против сайта. Тесты не ходят в сеть.
- Не объявлять «готово» без запуска: команда, вывод, что проверено.
- Вежливый краулинг: не чаще 1 запроса/сек, таймауты, ретраи с backoff, все внешние ошибки логируются и не роняют воркер.
- git remote не трогать, push не делать — это делается вручную.
