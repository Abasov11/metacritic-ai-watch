1. **Кнопка обхода бьёт по бюджету без ограничений.** `is_same_origin` сознательно пропускает запрос без `Origin` — голый `curl -X POST /monitor/run` получает 202 и запускает платный обход (ревьюер воспроизвёл: `crawl_runs #26`, reason=manual). Авторизации по заданию нет, поэтому ограничь ущерб, а не доступ:
   - глобальный cooldown ручных запусков `MANUAL_RUN_COOLDOWN_MINUTES` (по умолчанию 10): второй ручной запуск раньше — 429 с текстом «ручной запуск доступен через N мин», кнопка на `/monitor` показывает это состояние по SSE (не только `disabled`); плановые запуски cooldown не затрагивает;
   - дневной бюджет на модель `LLM_DAILY_BUDGET_USD` (по умолчанию 1.0): считать по `llm_calls.cost` за сегодня (та же таймзона, что у «дня» обхода); при исчерпании вызовы модели не делаются, игра сохраняется без резюме и остаётся «к повтору» (как при ошибке LLM), в мониторинге — плитка «бюджет дня: $x из $y» и событие `budget_exhausted`; `/healthz` отдаёт `llm_budget`;
   - README, раздел «Безопасность»: честно — кнопку может нажать кто угодно, ущерб ограничен cooldown + бюджетом + лимитом на игру; проверку Origin оставить как есть, но описать её точно (без Origin пропускается).
   Тесты: cooldown (второй запрос 429, после сдвига времени — 202), плановый запуск при активном cooldown идёт, бюджет исчерпан → модель не вызывается, игра due for retry, событие есть.
