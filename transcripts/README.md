# Переписка с нейросетью (raw JSONL)

Весь код проекта написан в диалоге с Claude Code (модель Claude Opus 5, CLI 2.1.263).
Здесь лежат необработанные транскрипты этой работы в том виде, в каком их пишет сам CLI.

## Как это было организовано

Задание разбито на шаги; каждый шаг — один промпт (файлы `prompts/step*.md`), который
подавался в одну и ту же сессию агента. После каждого шага я принимал результат сам:
запускал тесты, поднимал сервер, снимал скриншоты в headless-браузере, проверял базу
и живые страницы — и найденные дефекты возвращал агенту следующим промптом
(например, шаг 4b — обложки, шаг 8 — ложные совпадения летсплеев).

Агент работал в изолированном окружении: отдельный конфиг CLI без чужих инструкций и памяти,
проект вне домашнего каталога, чтобы в контекст не попало ничего постороннего.

## Что лежит в папке

| Файл | Что это |
|---|---|
| `prompts/step1.md … step8.md` | Мои промпты по шагам, дословно |
| `session-7e214985….jsonl` | Основная сессия: все шаги с 1 по 8 (промпты, рассуждения, вызовы инструментов, ответы) |
| `subagents/*.jsonl` | Субагенты, которых CLI поднимал для `/security-review` и `/code-review` на шаге 7 |
| `tool-results/*.txt` | Крупные выводы инструментов, вынесенные CLI из основного файла (на них есть ссылки в JSONL) |
| `session-23880206….jsonl` | Контрольный запрос перед началом работы: подтверждение, что в контексте агента нет посторонних инструкций |

## Что в файлах нет

Секретов: ключ OpenRouter лежал только в `.env`, агент его не печатал. В транскриптах
встречаются строки, похожие на ключи — `apiKey=1MOZ…`, `AIzaSy…`, `fastlyApiKey`, `clientToken` —
все они из клиентского конфига страниц metacritic.com, сайт отдаёт их в HTML каждому посетителю.
Перед публикацией папка прогнана через сканер секретов, других совпадений нет.
